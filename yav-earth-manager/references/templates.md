# Templates de Descrição por Tipo de Serviço

Catálogo de templates padronizados para os principais tipos de tarefa no LiveSEO Earth.
Use como referência ao gerar descrições no Modo 1 (Criar Tarefa).

---

## Cadastro de Produtos em Marketplace

```
## Objetivo
Cadastrar {quantidade} produtos da linha {nome} no {marketplace}.

## O que precisa ser feito
1. Revisar a planilha/base enviada pelo cliente
2. Verificar conformidade dos dados (título, descrição, EAN, imagens)
3. Cadastrar no painel do {marketplace} / Anymarket
4. Publicar os anúncios

## Critérios de Aceite (DoD)
- [ ] {quantidade} produtos cadastrados e publicados
- [ ] Imagens e descrições corretas
- [ ] Preços conforme planilha

## Canais / Sistemas envolvidos
{Marketplace}, Anymarket

## Referências
- [link da planilha]
```

## Campanha Promocional

```
## Objetivo
Criar campanha de {tema} no {marketplace} para o período {data_inicio} a {data_fim}.

## O que precisa ser feito
1. Definir produtos elegíveis com base no calendário comercial
2. Configurar descontos/cupons no painel do {marketplace}
3. Programar Flash Sales se aplicável
4. Aprovar com o cliente

## Critérios de Aceite (DoD)
- [ ] Campanhas criadas e agendadas
- [ ] Cliente aprovou os descontos
- [ ] Cupons programados e testados

## Canais / Sistemas envolvidos
{Marketplace}

## Referências
- [calendário comercial]
```

## Reporte Mensal / Gerencial

```
## Objetivo
Elaborar reporte mensal de {tipo: vendas/KPIs/desempenho} referente a {mês/ano}.

## O que precisa ser feito
1. Extrair dados de vendas do {sistema}
2. Consolidar indicadores (faturamento, ticket médio, conversão, etc)
3. Comparar com mês anterior e metas
4. Preparar apresentação/painel

## Critérios de Aceite (DoD)
- [ ] Dados extraídos e consolidados
- [ ] Reporte enviado ao cliente
- [ ] KPIs comparados com meta

## Canais / Sistemas envolvidos
{ERP, Marketplaces, GA4}

## Referências
- [link do dashboard]
```
